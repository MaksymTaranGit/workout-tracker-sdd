# Поетапний план розробки та критичний шлях (Development Plan & Critical Path)

Цей документ містить затверджений інженерний план розробки системи **Workout Volume & Progressive Overload Tracker** за методологією Specification-Driven Development (SDD) та Test-Driven Development (TDD).

---

## 1. Архітектурні принципи розробки

1. **Суворий TDD-конвеєр (Red $\to$ Green):** Кожна задача типу `Feature` заблокована (`Blocked By`) відповідним тікетом `Test`. Продуктовий код пишеться виключно після фіксації падіння автотестів.
2. **Розподіл відповідальності (RACI):**
   * **Кодинговий агент:** виконує `Test`, `Feature`, `Verification` та `Documentation` (швидкий темп: 10–25 хв на задачу).
   * **Людина (Tech Lead / QA):** виконує `Validation` та `Gate` (аналітичне рев'ю: 30–60 хв на задачу).
3. **Stage-Gate контроль:** Завершення кожного логічного блоку вимагає проходження задачі `Gate`, яка блокується виконанням `Verification` та `Validation` і блокує старт наступного етапу.

## 4. Розрахунок критичного шляху (Critical Path Method)

Розрахунок базується на формулі найдовшого послідовного шляху всередині кожного етапу:
$$\text{Stage Duration} = \max(\text{Branch}_1, \text{Branch}_2) + \max(\text{Verification}, \text{Validation}) + \text{Gate}$$

* **Етап 1:**
  * Паралельні гілки фіч: $\max(\text{TKT-01} + \text{TKT-02 } [35\text{m}], \text{TKT-03} + \text{TKT-04 } [35\text{m}]) = 35\text{ хв}$
  * Паралельний контроль: $\max(\text{TKT-05 } [10\text{m}], \text{TKT-06 } [45\text{m}]) = 45\text{ хв}$
  * Контрольна точка: $\text{TKT-07} = 30\text{ хв}$
  * **Критичний шлях Етапу 1: 110 хв (1.83 год / 1 год 50 хв)**

* **Етап 2:**
  * Паралельні гілки фіч: $\max(\text{TKT-08} + \text{TKT-09 } [35\text{m}], \text{TKT-10} + \text{TKT-11 } [35\text{m}]) = 35\text{ хв}$
  * Паралельний контроль: $\max(\text{TKT-12 } [10\text{m}], \text{TKT-13 } [45\text{m}]) = 45\text{ хв}$
  * Контрольна точка: $\text{TKT-14} = 30\text{ хв}$
  * **Критичний шлях Етапу 2: 110 хв (1.83 год / 1 год 50 хв)**

* **Етап 3:**
  * Паралельні гілки фіч: $\max(\text{TKT-15} + \text{TKT-16 } [35\text{m}], \text{TKT-17} + \text{TKT-18 } [25\text{m}]) = 35\text{ хв}$
  * Паралельний контроль: $\max(\text{TKT-19 } [10\text{m}], \text{TKT-20 } [45\text{m}]) = 45\text{ хв}$
  * Контрольна точка: $\text{TKT-21} = 30\text{ хв}$
  * **Критичний шлях Етапу 3: 110 хв (1.83 год / 1 год 50 хв)**

* **Етап 4:**
  * Паралельні гілки фіч: $\max(\text{TKT-22} + \text{TKT-23 } [35\text{m}], \text{TKT-24} + \text{TKT-25 } [40\text{m}]) = 40\text{ хв}$

  * Контрольна точка: $\text{TKT-28} = 45\text{ хв}$
