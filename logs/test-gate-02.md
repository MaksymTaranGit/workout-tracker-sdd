## 1. Контекст та охоплення вимог Блоку 2 (`TKT-08`, `TKT-10`)

Тестовий набір Блоку 2 покриває математичні обчислення $W_{eff}$ та `Volume Load`, бізнес-правила виключення розминочних підходів, ізоляцію блоків та валідацію знаків ваги:

* **Функціональні вимоги:** `REQ-F-006`, `REQ-F-007`, `REQ-F-008`, `REQ-F-009`, `REQ-F-010`, `REQ-F-021`.
* **Критерії приймання:** `AC3`, `AC4`, `AC5`.
* **BDD-сценарії:**
  * `BDD-001` — повна незмінність `set_volume_load` і `block_volume_load` у минулій сесії (та для нових підходів у ній) після зміни `current_body_weight` у профілі.
  * `BDD-002` — розрахунок для вправ із компенсацією ваги (гравітрон `ASSISTED`: $W_{eff} = 80 + (-20) = 60$ кг, $VL = 600$ кг).
  * `BDD-003` — виключення розминочних підходів (`is_warmup=True` $\to$ `set_volume_load = 0.0`) із підсумкового тоннажу блоку.
* **Бар'єри реєстру ризиків:**
  * `RSK-06` — використання виключно `body_weight_snapshot` сесії при розрахунку $W_{eff}$.
  * `RSK-07` — доменні перевірки знака ваги (`ERR_NEGATIVE_WEIGHT_NOT_ALLOWED` для `STANDARD <= 0` та `BODYWEIGHT < 0`; `ERR_POSITIVE_WEIGHT_IN_ASSISTED` для `ASSISTED > 0`; `ERR_NON_POSITIVE_EFFECTIVE_LOAD` при $W_{eff} \le 0$).
  * `RSK-09` — повна ізоляція `block_volume_load` між кількома блоками однієї вправи в межах сесії.
