# Журнал конфігурації кодингового агента

- **Середовище виконання:** Antigravity IDE / Execution Environment
- **Клас інструменту:** Автономний асистент розробки на базі LLM (Coding Agent)
- **Модель агента:** Вбудована модель кодогенерації середовища Antigravity
- **Спосіб доступу до репозиторію:** Прямий доступ до локальної файлової системи робочого простору проєкту та інтегрованого терміналу.

## Дозволені операції в середовищі
1. Читання структури каталогів та файлів проєкту (`/spec`, `/src`, `/tests`, `/docs`, `/logs`).
2. Внесення змін до файлів специфікацій та кодової бази за явним запитом розробника.
3. Формування пропозицій щодо коду, тестів та документації згідно зі специфікаціями SDD.

## Обмеження агента
- Заборонено неконтрольоване автоматичне злиття конфліктів у системі Git без верифікації людиною.
- Будь-яка генерація коду має суворо слідувати артефактам у `/spec`.
