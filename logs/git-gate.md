# Журнал контрольної точки GIT-GATE: Вирішення конфлікту специфікації

- **Дата:** 2026-09-15
- **Об'єкт конфлікту:** `spec/intent.md` (розділ 2, вимога до розрахунку 1RM)
- **Конфліктуючі гілки:** `human/1rm-brzycki` (зміна людини) та `agent/1rm-epley` (зміна кодингового агента)

## Суть конфлікту
Агент запропонував формулу Epley ($r \le 10$), тоді як людина паралельно внесла формулу Brzycki ($r < 12$). Обидві зміни змінювали той самий рядок і пропонували взаємовиключні математичні апарати розрахунку.

## Обґрунтування рішення (SDD)
Рішення прийнято не за ознакою авторства чи часу створення коміту, а на основі аналізу системних вимог:
1. Початковий опис задуму виявився неповним щодо визначення єдиного стандарту розрахунку силових показників.
2. Для запобігання втраті аналітичного контексту обрано стратегію синтезу: Epley зафіксовано як базову модель для коротких серій ($r \le 10$), а Brzycki внесено як альтернативну модель.

## Питання для опрацювання (SRS)
- Чи має система надавати користувачеві можливість вибору математичної моделі 1RM у налаштуваннях?
- Яку формулу обрати за замовчуванням для ізольованих вправ з діапазоном повторень $r > 10$?
